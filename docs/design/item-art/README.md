# Party item artwork

Dedicated native artwork for items that were added with the co-operative
content and had been borrowing another item's tile. Generated by Codex with the
built-in image tool on 31 October 2026. [Preview](preview.png) shows every asset
enlarged, at native size, and at twice native size, composited as the game
composites it.

## Assets

Stamps are the 15 pixel corner glyphs Crawl layers over a base item:

- Scrolls: soul recall, rallying, phase swap, shared vigour, collection, wish.
- Potions: empathy, soul ambrosia, concord, transfusion.
- Jewellery: ring of camaraderie, amulet of the vanguard.

Tiles are full 32 by 32 sprites:

- Evokers: aegis standard, astral beacon, twin-spark conduit, skald horn. The
  first three have a spent sprite.
- Archaeologist's ancient crate and dusty tome.
- Pouch, satchel and mercenary contract. The bag of plenty keeps the existing
  carry bag sprite, so each capacity tier now looks different.

Symbols follow each item's description in `dat/descript/items.txt` and avoid
the silhouettes of existing stamps on the same base. Scroll backgrounds keep
Crawl's colour families: cyan for rare rewards, purple for translocation, green
for benefits, yellow for restoration, brown for calling allies.

`dc-item.txt` lists stamps in enum order because the game indexes them as
`ID_FIRST + type`. The wyrm essences stay outside the potion label range.

## Generation and provenance

[prompts.json](prompts.json) retains the final prompt and native target of every
asset. `sources/` preserves the selected generated PNGs. `runs/` holds one log
per generation round, with the hash, revised prompt and attempts of each
output; [manifest.json](manifest.json) records the source and native tile
hashes. An asset's latest log entry is the source in use.

Generation ran as `codex exec` in `workspace-write` mode inside this folder,
using the built-in `image_gen` tool, no API key and
`references/native-style-reference.png` as a style reference:

1. Pilot of three assets, which proved the stamp brief and rejected the first
   tile brief. It produced an illustration that turned to noise at 32 pixels.
2. Batch of the other 18 assets and the rejected tile, on a stricter brief.
3. Revision of eight assets that did not survive reduction, judged at native
   size. Empathy read as heart-shaped sunglasses, the rallying shaft and the
   phase swap arrowheads vanished, concord lacked contrast on the gold label,
   the conduit read as a hacksaw, and the crate, tome and satchel turned to
   speckle.

`prepare.py` only normalizes generated artwork: crop to opaque bounds, fit
native bounds, take each pixel's dominant colour from a reduced palette, and
threshold alpha to native opaque or transparent pixels. It draws no artwork.
Spent evokers are a desaturated copy of the ready sprite, as native ones are.

```
python3 prepare.py                    # preview only
python3 prepare.py --install          # write rltiles/item tiles and manifest.json
```

Install refuses to overwrite an existing tile. Normal native builds regenerate
the atlases and tile metadata without any image service or runtime dependency.
